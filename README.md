# 🚀 NOVA TOOLS PRO

### Your All-in-One Productivity Workspace

**NOVA TOOLS PRO** is a modern, responsive, all-in-one productivity dashboard designed to make your daily workflow faster, smarter, and more organized.

🌐 **Live Demo:** https://smsrabon.github.io/Nova-tools-pro/

---

## ✨ Features

- 📊 **Dashboard & Analytics** — Track your productivity and activities.
- ✅ **Task Manager** — Organize and manage daily tasks.
- 📝 **Smart Notes** — Save your important ideas and notes.
- ⏱️ **Focus Timer** — Stay focused with a Pomodoro timer.
- 🧮 **Calculator** — Perform quick mathematical calculations.
- 🔤 **Text Toolkit** — Transform and analyze text.
- `{ }` **JSON Formatter** — Format, minify, and validate JSON.
- 🔐 **Password Generator** — Generate random passwords.
- 🔄 **Unit Converter** — Convert common measurement units.
- 💱 **Currency Converter** — Convert currencies using online exchange rates.
- 🎨 **Color Studio** — Pick and copy color codes.
- 📱 **QR Generator** — Generate QR codes.

## 🎨 Design & Experience

- Clean and modern user interface
- Apple-inspired design aesthetics
- Responsive layout for desktop, tablet, and mobile
- Light and dark mode
- Easy navigation and quick access
- Browser-based data storage

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
- External APIs for online features

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/smsrabon/Nova-tools-pro.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

No installation or build process is required.

## 🔒 Privacy & Data

- Workspace data is stored locally in your browser.
- The login interface is a demo feature, not secure server-side authentication.
- Currency conversion and QR generation may require an internet connection.
